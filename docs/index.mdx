ami-rust packages a pinned Rust compiler, Cargo, AROS target libraries, a relocatable C SDK and native link tools. It deliberately stays close to upstream Rust: `rustup` selects the toolchain, standard Cargo builds applications, and AROS support arrives through ordinary crates.

There is no project-specific CLI, Cargo wrapper or Python runtime dependency. The initial release covers `no_std` plus `alloc`; full `std`, additional AROS architectures and a native AROS-hosted compiler are future work.
