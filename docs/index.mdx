ami-rust packages a pinned Rust compiler, Cargo, AROS target libraries, a relocatable C SDK and native link tools. It deliberately stays close to upstream Rust: `rustup` selects the toolchain, standard Cargo builds applications, and AROS support arrives through ordinary crates.

There is no project-specific CLI, Cargo wrapper or Python runtime dependency. The initial release covers `no_std` plus `alloc`; full `std`, additional AROS architectures and a native AROS-hosted compiler are future work.

## Read in this order

1. [Install and build](/quickstart-toolchain/) installs the toolchain and configures Cargo.
2. [Crates and consumer guide](/consumer-guide/) shows which crates to use, with a complete text program and a complete MUI program.
3. [Run on AROS](/run-on-aros/) gets the result onto a system and starts it.
4. [Targets and ABIs](/targets-and-abis/) explains ABI-v1 and ABI-v11 and which one to build for.
5. [Programming model](/api/) explains ownership, lifetimes and failure, and the [API reference](/reference/) lists every item.
6. [MUI hello](/mui-hello/) and the [SHA-256 example](/sha256sum/) are small programs to build and read.

If something does not build or start, see [Troubleshooting](/troubleshooting/).
