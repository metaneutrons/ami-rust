# ami-rust artwork

Original vector artwork for ami-rust: `ami-rust-mark.svg` is the compact mark;
`ami-rust-hero.svg` is the repository header. Both are self-contained SVGs with
accessible titles and descriptions, no embedded scripts or remote resources.
The artwork is available under the repository's MIT OR Apache-2.0 terms.

Raster documentation and product images are versioned as WebP by default.
`mui-hello-abi11.webp` is a focused crop from the native ABI-v11 QEMU capture
referenced by the consumer guide. SVG remains the canonical format for the
ami-rust mark and hero because they are vector artwork.
