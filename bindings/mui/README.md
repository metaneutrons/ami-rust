# Canonical MUI API model

This directory contains the reviewed inputs and deterministic output for the
public MUI API surface used by ami-rust. Application builds consume committed
Rust bindings; they never run this generator or require an AROS source tree.

`sources.json` pins the ABI1 and ABI11 repositories, commits, source root, and
public entry header. The generator follows quoted includes from `mui.h`, reads
every selected header from the pinned Git object, and derives superclass
relations from the class descriptors at the same commit. `overrides.json`
contains the small reviewed exception set. An exception needs an explicit
reason; the generator rejects duplicate or unexplained entries.

`api.json` classifies every macro and enum value in the selected headers,
records all `MUIP_*` message structures and fields, and preserves version,
access, visibility, source, and expression information. `provenance.json`
identifies every consulted header and class-descriptor source by repository,
commit, path, role, and SHA-256 digest.

Generate the committed model from local clones containing the pinned commits:

```sh
cargo +1.98.1 xtask generate mui \
  --repository . \
  --abi1-source /path/to/AROS-NX \
  --abi11-source /path/to/deadwood-AROS
```

Use `check mui` with the same arguments to compare the generated bytes without
writing them. Unsupported expressions in the MUI identifier namespaces fail
explicitly. Maintainers may add a raw-expression exception only after review;
the expression and reason remain in the committed model and override file.
