Cargo registry · crates.metaneutrons.cc

Safe Rust crates for AROS.

The aros-* library crates of ami-rust, for the x86_64-unknown-aros-abi1 and x86_64-unknown-aros-abi11 targets. A read-only static sparse registry: there is no publish API, and a published version never changes.

Use it Crates Consumer guide Source

Use it

Name the registry once in .cargo/config.toml, then depend on the crates as usual.

# .cargo/config.toml
[registries.metaneutrons]
index = "sparse+https://crates.metaneutrons.cc/"
# Cargo.toml
[dependencies]
aros = { version = "0.2", registry = "metaneutrons", default-features = false }

The crates are no_std and build with the ami-rust toolchain, not with a stock Rust. The README shows how to install it, and the consumer guide covers linking, the two ABI profiles and a first program.

What you can rely on

Append-only

A published version is never changed or removed. Publication refuses to write a version again with different bytes.

Checked

Every index line carries the SHA-256 of its archive, which Cargo verifies on download. Releases read every byte back from this host.

Static

Plain files on Cloudflare R2, no server and no publish API. Crates are written first and index files after them.

Temporary home

The crates also stay available from the Git repository, and they move to crates.io once they have stabilised.
