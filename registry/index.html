crates.metaneutrons.cc

A read-only Cargo registry for the ami-rust aros-* crates (Rust for AROS). It is a static sparse index: there is no publish API, and published versions never change. The crates are published here with each ami-rust release and will move to crates.io once they have stabilised.

Use it

In .cargo/config.toml:

[registries.metaneutrons]
index = "sparse+https://crates.metaneutrons.cc/"

In Cargo.toml:

[dependencies]
aros = { version = "0.2", registry = "metaneutrons" }

The crates build for the x86_64-unknown-aros-abi1 and x86_64-unknown-aros-abi11 targets with the ami-rust toolchain; see the README for installation.
