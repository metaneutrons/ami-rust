---
title: Compatibility
description: The supported host, target and runtime boundary for 0.1.0.
---

The qualified development hosts are macOS 26 on Apple Silicon, Ubuntu 24.04 on x86-64 and Ubuntu 24.04 on ARM64. Each host produces AROS x86-64 ELF output for both ABI variants.

| Scope | 0.1.0 support |
| --- | --- |
| Development hosts | macOS Apple Silicon; Linux x86-64 and ARM64 |
| AROS target CPU | x86-64 |
| AROS ABI | ABI-v1 and ABI-v11 |
| Rust surface | `no_std` and `alloc` |
| Tooling | rustup and Cargo |

The release does not claim support for full Rust `std`, native AROS-hosted rustc/Cargo/rustup, other AROS CPU targets, or registry publication of the crates. See [Targets and ABI](/targets/) for the exact target names.
