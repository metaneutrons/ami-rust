---
title: Crates and APIs
description: The initial Cargo library surface for AROS applications.
---

The public crates are delivered from the ami-rust repository until their names and API contracts are stable enough for an intentional crates.io release. Depend on the repository revision selected by your project; commit `Cargo.lock`.

| Crate | Purpose |
| --- | --- |
| `aros` | Entry, allocation and safe AROS core API. |
| `aros-sys` | Raw ABI declarations for explicit low-level work. |
| `aros-mui` | Task-affine, ownership-aware MUI API. |
| `aros-mui-sys` | Raw MUI vector calls. |
| `aros-elf` | Maintainer ELF support, not application API. |
| `aros-native-build` | Maintainer build support, not application API. |

Start from the safe crate where it models the operation you need. Use `*-sys` only at a deliberately contained FFI boundary and retain the native API's lifetime, ownership and task-affinity rules there.

The [API guide in the repository](https://github.com/metaneutrons/ami-rust/blob/main/docs/api.md) records the current capabilities and explicit limits of every crate.
