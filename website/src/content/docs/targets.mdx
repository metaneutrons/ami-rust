---
title: Targets and ABI
description: A target triple selects the ABI boundary exactly.
---

ami-rust exposes two initial targets:

```text
x86_64-unknown-aros-abi1
x86_64-unknown-aros-abi11
```

The suffix is intentional. ABI-v1 and ABI-v11 are distinct AROS ABI contracts. Build the same application independently for the ABI it will run against; do not combine them in a single binary and do not use a Cargo feature to choose one at runtime.

The target CPU is `x86_64`. The host architecture is separate: macOS Apple Silicon and Linux x86-64/ARM64 are supported cross-compilation hosts. Future AROS AArch64 and RV32 targets need their own toolchain and qualification work; they are not implied by this release.
