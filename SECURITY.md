# Security reporting

The public CI workflow tests local installer fixtures. It does not establish
publisher identity or protected build provenance, and this repository currently
has no SDK release channel or release signing key.

If private vulnerability reporting is enabled by the repository host, use that
channel. Otherwise contact a maintainer through the contact details on the
maintainer's hosting profile before sharing exploit details. Do not attach
credentials, private data, or unpublished signing material to a public issue.
No response time or support period is promised.
